# DMMA Brain Explorer — Documentation & Maintenance Guide

Standalone interactive 3D neuroscience education platform for **drmilladmikhail.com** (`/brain-explorer/`).

## Directory Structure
- `index.html` — Standalone RTL page with strict CSP (`script-src 'self'`), SEO metadata, and JSON-LD.
- `css/brain-explorer.css` — Deep navy, gold, and neural-blue scientific museum styling.
- `vendor/three/` — Self-hosted Three.js ES modules (zero external CDN dependencies).
- `models/human-brain-segmented.glb` — 15-mesh segmented binary glTF 2.0 brain model (generated by `tools/build_brain_glb.py`).
- `data/` — JSON educational datasets (`regions.json`, `modes.json`, `behavior.json`, `glossary.json`, `quizzes.json`, `references.json`).
- `js/` — Modular ES scripts (`main.js`, `brain-viewer.js`, `fallback-2d.js`, `modes-controller.js`, `neuron-lab.js`, `knowledge-center.js`).

## How to Add a New Brain Region
1. Add the new 3D mesh with a unique `name` in `tools/build_brain_glb.py` and re-run:
   ```bash
   python tools/build_brain_glb.py
   ```
2. Add a matching entry (same `id`) with all 9 Arabic/English fields in `brain-explorer/data/regions.json`.
3. Optionally add a matching 2D SVG shape in `brain-explorer/js/fallback-2d.js`.

## How to Add New Lessons, Modes, or Quiz Questions
- **Psychological Modes:** Append an object to `brain-explorer/data/modes.json` referencing valid `regionId` values from `regions.json`.
- **Brain-to-Behavior Topics:** Append an entry to `brain-explorer/data/behavior.json` with verified internal article links.
- **Quizzes & Flashcards:** Edit `brain-explorer/data/quizzes.json` (`levels.beginner`, `intermediate`, `advanced`, and `flashcards`).
- **Glossary & References:** Edit `brain-explorer/data/glossary.json` and `brain-explorer/data/references.json`.

## Deployment on GitHub Pages
- The `/brain-explorer/` directory is completely self-contained and automatically included in `_site/` by `.github/workflows/verified-site.yml` when pushed to `main`.
- No build step or backend server is required at runtime.
